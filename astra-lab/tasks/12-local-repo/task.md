# Локальный репозиторий

В компании нет доступа к интернету, а корпоративные программы приходят файлами `.deb`. Их положили в `/srv/debs`. Ставить их по одному через `dpkg -i` неудобно: приходится вручную искать зависимости. Сделайте локальный репозиторий.

**Нужно:**
1. Создать репозиторий в каталоге `/srv/repo`: скопировать туда пакеты из `/srv/debs` и создать индекс пакетов (`Packages` или `Packages.gz`).
2. Подключить репозиторий в apt отдельным файлом в `/etc/apt/sources.list.d/`. Репозиторий не подписан, apt должен ему доверять.
3. Установить пакет `corp-agent` **через apt** из этого репозитория. Его зависимость `corp-common` должна подтянуться автоматически.

**Подсказка:** индекс создаёт `dpkg-scanpackages` (пакет `dpkg-dev`): запускайте его из `/srv/repo`, вывод сожмите `gzip` в `Packages.gz`. Строка источника для «плоского» репозитория: `deb [trusted=yes] file:/srv/repo ./`. После подключения — `apt update`. Строки вида «Файл не найден … Packages.xz» при этом — не ошибка: apt ищет индекс в разных форматах сжатия. Проверить: `apt-cache policy corp-agent`.
