# Разбор журнала веб-сервера

Пользователи жаловались на ошибки портала. Руководитель просит отчёт по журналу `/var/log/portal/access.log`. Формат строк обычный для веб-серверов: адрес клиента, дата, запрос, **код ответа** (9-е поле), размер ответа в байтах, источник и браузер.

```
10.0.5.17 - - [30/Oct/2026:10:00:01 +0300] "GET /docs/500 HTTP/1.1" 200 404 "-" "Mozilla/5.0"
```

Коды 5xx (500–599) — ошибки сервера, 404 — страница не найдена.

**Нужно** создать каталог `/root/report` и в нём три файла:
1. `errors_5xx.txt` — все строки журнала, где код ответа 5xx, без изменений и в том же порядке.
2. `count_404.txt` — одно число: сколько запросов получили ответ 404.
3. `top3.txt` — три адреса клиентов, которые сделали больше всего запросов: по строке на адрес, сначала самый активный. В строке — число запросов и адрес (как выводит `uniq -c`).

Журнал не меняйте.

**Подсказка:** число 500 или 404 может встретиться в адресе страницы и в размере ответа. Ищите по полю, а не по всей строке: `awk '$9 ~ /^5/'`. Для подсчёта: `cut`/`awk`, `sort`, `uniq -c`, `sort -rn`, `head`.
