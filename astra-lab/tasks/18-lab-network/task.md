# Сеть учебного стенда

К серверу подключают стенд разработчиков. Стенд пока доступен через виртуальный интерфейс. Настройте сеть так, чтобы настройки сохранялись после перезагрузки.

**Нужно:**
1. Создать интерфейс `lab0` типа `dummy` с адресом `10.20.0.1/24`. Сделайте это подключением NetworkManager (оно сохранится после перезагрузки), а не только командой `ip`.
2. Добавить в это же подключение статический маршрут: сеть `10.30.0.0/16` через шлюз `10.20.0.254`. Маршрут по умолчанию не трогайте.
3. Сервер репозитория `10.20.0.5` должен открываться по именам `repo.lab` и `repo`. DNS-сервера для стенда нет.
4. Служба SSH на этом сервере перенесена на нестандартный порт. Узнайте, какой порт сейчас слушает `sshd`, и запишите только число в файл `/root/ssh-port.txt`.

**Подсказка:**
- `nmcli connection add type dummy ifname lab0 con-name lab0 ipv4.method manual ipv4.addresses …`; маршрут — свойство `ipv4.routes`; после `nmcli connection modify` выполните `nmcli connection up lab0`;
- если вы уже создали `lab0` командой `ip link add`, NetworkManager не возьмёт его под управление: удалите его (`ip link del lab0`) и активируйте подключение снова;
- проверить: `ip -br addr`, `ip route`, `ip route get 10.30.1.1`;
- имена без DNS — файл `/etc/hosts`, проверка `getent ahostsv4 repo.lab`;
- слушающие порты и процессы — `ss -tlnp`.
