# Новые сотрудники отдела кадров

В отдел кадров приходят два сотрудника. Ещё один сотрудник, `ivanov_old`, уволился. Его учётная запись уже есть в системе.

**Нужно:**
1. Создать группу `kadry`.
2. Сделать так, чтобы у каждого **нового** пользователя в домашнем каталоге появлялся файл `PRAVILA.txt` с правилами работы (текст любой).
3. Создать пользователей `sidorova` и `kuznetsov`:
   - домашний каталог `/home/имя`, в нём есть `PRAVILA.txt`;
   - оболочка `/bin/bash`;
   - дополнительная группа `kadry`;
   - пароль задан (любой), но при первом входе пользователь обязан его сменить;
   - пароль действует не больше 90 дней, предупреждение — за 14 дней.
4. `kuznetsov` работает по договору: его учётная запись должна перестать действовать после 31 декабря 2026 года (дата окончания — `2026-12-31`).
5. Запретить вход `ivanov_old`. Учётную запись и домашний каталог не удаляйте: там остались документы.

**Подсказка:** `groupadd`, `useradd` с ключами `-m`, `-s`, `-G`; шаблон домашнего каталога — `/etc/skel`; пароль — `passwd` или `chpasswd`; сроки — `chage`. Проверить: `chage -l kuznetsov`, `id sidorova`, `passwd -S ivanov_old`.
