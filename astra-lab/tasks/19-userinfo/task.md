# Скрипт: сведения о пользователе

Служба поддержки часто спрашивает, какой UID, домашний каталог и оболочка у пользователя. Напишите для неё скрипт.

**Нужно:** создать исполняемый скрипт `/usr/local/bin/userinfo` на bash.

1. `userinfo ИМЯ` выводит **одну строку** через пробел: имя, UID, домашний каталог, оболочка — и завершается с кодом `0`. Пример:
   ```
   $ userinfo root
   root 0 /root /bin/bash
   ```
2. Если пользователя нет, скрипт пишет сообщение об ошибке в **поток ошибок** (stderr), в обычный вывод не пишет ничего и завершается с кодом `1`.
3. Если аргумент не указан или аргументов больше одного, скрипт пишет в stderr подсказку `Использование: userinfo ИМЯ` и завершается с кодом `2`.
4. Скрипт работает и под обычным пользователем, не только под root.

Проверка запускает скрипт много раз на разных пользователях и проверяет вывод и коды возврата.

**Подсказка:** запись о пользователе выдаёт `getent passwd ИМЯ` (код возврата не 0, если пользователя нет). Поля разделены `:` — разберите их через `IFS=: read -r …` или `cut -d:`. Количество аргументов — `$#`, вывод в stderr — `>&2`, выход с кодом — `exit N`. Не забудьте первую строку `#!/bin/bash` и `chmod +x`.
