# Общая папка отдела

Отдел продаж просит общую папку. В системе уже есть группа `otdel` с пользователями `ivanova` и `petrov`. Пользователь `smirnov` в отдел не входит.

**Нужно:**
1. Создать каталог `/srv/otdel`. Владелец — `root`, группа — `otdel`.
2. Участники `otdel` могут создавать файлы в папке. Остальные пользователи не могут даже посмотреть её содержимое.
3. Новые файлы и подкаталоги автоматически получают группу `otdel`.
4. Файл, который создала `ivanova`, может изменить `petrov`, и наоборот. Настройки пользователей (umask, профили) не меняйте.

**Подсказка:** вам понадобятся `chgrp`, `chmod` со специальным битом и ACL по умолчанию (`setfacl -m d:...`).

Проверить себя вручную: `su - ivanova -c 'touch /srv/otdel/t1'`, затем `su - petrov -c 'echo test >> /srv/otdel/t1'`.
