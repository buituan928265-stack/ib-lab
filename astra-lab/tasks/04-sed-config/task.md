# Правка конфигурации через sed

Сервер базы данных переехал, а приложение учёта до сих пор пишет подробную отладку. Исправьте файл `/etc/uchet/uchet.conf`. Открывать его в редакторе можно, чтобы посмотреть, но представьте, что таких серверов сто: правку удобно сделать командой `sed`, которую потом можно запустить везде.

**Нужно:**
1. Перед правкой сохранить исходный файл как `/etc/uchet/uchet.conf.bak` (точная копия).
2. Заменить **все** упоминания `db-old.local` на `db01.corp.local`, в том числе когда их несколько в одной строке.
3. Уровень журнала: строка `log_level = debug` должна стать `log_level = warning`. Строку-пример в комментарии в начале файла не трогать.
4. Закомментировать (поставить `#` в начало) все строки, которые **начинаются** с `debug_`. Другие строки, где `debug` стоит в середине, не трогать.
5. Остальные строки оставить как есть.

**Подсказка:** `sed -i.bak` сохраняет копию. Флаг `g` в `s/…/…/g` заменяет все совпадения в строке. Якорь `^` — начало строки. Точку в имени сервера экранируйте: `db-old\.local`. Проверить изменения: `diff /etc/uchet/uchet.conf.bak /etc/uchet/uchet.conf`.
