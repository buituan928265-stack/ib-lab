# Порядок в обменнике

Каталог `/srv/exchange` — файловый обменник отдела. Он переполнен: программы оставляют временные файлы `*.tmp`, после переездов остались ссылки в никуда, а кто-то складывает туда большие файлы. Наведите порядок. Файлы лежат и во вложенных каталогах.

**Нужно:**
1. Удалить все файлы с расширением `.tmp`, которые не менялись больше 7 дней. Свежие `.tmp` не трогайте: их, возможно, ещё пишут. Другие файлы тоже не трогайте, даже если в их имени есть `tmp`.
2. Удалить все битые символические ссылки — те, что указывают на несуществующий файл. Рабочие ссылки оставить.
3. Записать в файл `/root/big_files.txt` полные пути (от `/`) всех обычных файлов в `/srv/exchange` размером больше 5 МБ — по одному на строку, порядок любой. Сами большие файлы не удалять.

**Подсказка:** `find` с условиями `-name`, `-type`, `-mtime`, `-size`, действия `-delete` или `-exec`. Битую ссылку находит `find -xtype l`. Сначала посмотрите список без `-delete`.
