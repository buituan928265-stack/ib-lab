# Окружение для сопровождающего приложения

Пользователь `smirnov` сопровождает приложение учёта. Оно установлено в `/opt/uchet`: программа управления `/opt/uchet/bin/uchetctl`, журнал `/var/log/uchet/uchet.log`. Смирнов жалуется, что каждый раз набирает длинные пути. Настройте ему окружение.

**Нужно** (всё должно работать сразу после входа `smirnov` в систему, в том числе после перезагрузки):
1. Переменная окружения `UCHET_HOME` со значением `/opt/uchet`. Её видят и программы, которые запускает Смирнов (переменная экспортирована).
2. Каталог `/opt/uchet/bin` добавлен в `PATH`: команда `uchetctl` запускается просто по имени. Системные каталоги из `PATH` не пропадают.
3. Псевдоним `uchetlog` показывает последние 20 строк журнала `/var/log/uchet/uchet.log`.
4. Это настройки только для `smirnov`: у других пользователей (например, `petrova`) их быть не должно.

**Подсказка:** переменные окружения обычно задают в `~/.profile`, псевдонимы — в `~/.bashrc`. Проверить: `su - smirnov`, затем `echo $UCHET_HOME`, `type uchetctl`, `uchetlog`.
