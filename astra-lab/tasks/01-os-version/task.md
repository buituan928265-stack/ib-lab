# Версия системы и ядра

Отдел ИБ составляет опись серверов и просит прислать точную версию операционной системы и ядра этой машины. В каталоге `/root` лежит старая опись `inventory-2024.txt`, но сведения в ней устарели — не копируйте их, а узнайте всё у самой системы.

**Нужно:** создать файл `/root/version.txt` ровно из двух строк такого вида:

```
os=<полное название системы из PRETTY_NAME в /etc/os-release>
kernel=<версия ядра, которую выводит uname -r>
```

Например (значения на вашей машине будут другими):

```
os=Debian GNU/Linux 11 (bullseye)
kernel=5.10.0-21-amd64
```

**Подсказка:** название системы — `cat /etc/os-release` или `grep PRETTY_NAME /etc/os-release`, версия ядра — `uname -r`. Кавычки вокруг названия в файл не переносите. На настоящей Astra Linux номер обновления дополнительно смотрят в `/etc/astra_version`, а в нашей лаборатории на Debian 12 этого файла нет.
