# Первые шаги в лаборатории

Это пробное задание. Оно нужно, чтобы привыкнуть к лаборатории: получить задание, выполнить его и получить код для Stepik.

Коллега оставил для вас записку — файл `start-here.txt` где-то внутри каталога `/srv`. Где именно, он не помнит.

**Нужно:**
1. Найти файл `start-here.txt` в каталоге `/srv` и его подкаталогах.
2. Создать каталог `/root/practice`.
3. Скопировать найденный файл в `/root/practice/`, имя файла не меняйте.
4. В записке есть кодовое слово. Запишите его в файл `/root/practice/answer.txt` — одно слово в одной строке.

**Подсказка:** найти файл по имени поможет `find /srv -name start-here.txt`. Прочитать файл — `cat`, создать каталог — `mkdir`, скопировать — `cp`. Записать слово в файл: `echo слово > /root/practice/answer.txt`.
