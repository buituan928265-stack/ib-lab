# Порядок в пакетах

На сервере нужно навести порядок в пакетах.

**Нужно:**
1. Узнать, какому пакету принадлежит файл `/usr/bin/lsattr`. Запишите имя пакета (только имя, одно слово) в файл `/root/paket.txt`.
2. Старый агент мониторинга, пакет `old-agent`, больше не нужен. Удалите его **полностью**, вместе с файлами настроек: в системе не должно остаться ни пакета, ни `/etc/old-agent.conf`.
3. Пакет `openssh-server` нельзя обновлять, пока не проверят новую версию. Запретите apt его обновлять.
4. Установите программу `report-tool` из файла `/root/pkgs/report-tool_1.0_all.deb`. Она зависит от пакета `report-lib`, его файл лежит в том же каталоге.

**Подсказка:** `dpkg -S`, `apt purge` или `dpkg -P`, `apt-mark`. Пакет из файла: `apt install ./файл.deb` (с `./`!) или `dpkg -i` для всех нужных файлов. Проверить: `dpkg -l | grep -E 'old-agent|report'`, `apt-mark showhold`.
