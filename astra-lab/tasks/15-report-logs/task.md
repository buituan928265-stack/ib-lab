# Журналы службы отчётов

На сервере работает служба `report-gen`: каждые 10 секунд она пишет отчёт в `/var/lib/report-gen/last-report.txt`. Пользователи жалуются, что отчёты не обновляются. Кроме того, после перезагрузки сервера в журнале не остаётся сообщений за прошлые дни.

**Нужно:**
1. По журналу узнать, почему служба `report-gen` не работает, и устранить причину. Служба должна работать (`active`), запускаться при загрузке и по-прежнему работать от пользователя `report`. Права «для всех» (`777`) не давайте.
2. Включить постоянное хранение журнала systemd: записи должны сохраняться на диске в `/var/log/journal`.
3. Настроить syslog-ng: все сообщения программы `report-gen` дополнительно записывать в файл `/var/log/report-gen.log`. Сообщения других программ в этот файл попадать не должны.
4. Настроить ротацию `/var/log/report-gen.log` в logrotate: каждый день, хранить 7 старых файлов, сжимать их, не выдавать ошибку, если файла нет.

**Подсказка:**
- `systemctl status report-gen`, `journalctl -u report-gen -p err -b`;
- `Storage=` в `/etc/systemd/journald.conf`, затем перезапуск `systemd-journald`;
- свой файл в `/etc/syslog-ng/conf.d/` с `filter { program("report-gen"); }`, проверка `syslog-ng -s`, затем `systemctl reload syslog-ng`;
- свой файл в `/etc/logrotate.d/`, проверка `logrotate -d /etc/logrotate.d/report-gen`.
