# Новый диск для архива

На сервер добавили диск под архив документов. В лаборатории настоящего диска нет, поэтому диском будет файл-образ, подключённый как loop-устройство (блочное устройство поверх файла). Дальше всё как с обычным диском: таблица разделов, раздел, файловая система, монтирование через `/etc/fstab`.

**Нужно:**
1. Создать файл-образ `/srv/disk.img` размером 200 МБ и подключить его как loop-устройство с поддержкой разделов.
2. Создать на устройстве таблицу разделов GPT и один раздел на всё свободное место.
3. Создать на разделе файловую систему ext4 с меткой `ARCHIVE`.
4. Добавить строку в `/etc/fstab`: раздел монтируется в каталог `/mnt/archive`, устройство указано по **UUID**, в параметрах есть `nofail` (сервер загрузится, даже если диск не подключён).
5. Смонтировать раздел через fstab: команда `mount /mnt/archive` без других аргументов должна работать.

**Подсказка:** `truncate` или `dd`, `losetup -fP --show`, `parted` или `fdisk`, `mkfs.ext4 -L`, `blkid`, `findmnt --verify`.

**Особенность лаборатории.** В контейнере нет службы udev, поэтому файлы разделов `/dev/loopNp1` сами не появляются, хотя ядро раздел видит (`lsblk`). После разметки выполните `lab-partnodes /dev/loopN` — команда создаст недостающие файлы устройств. На настоящем сервере это делает udev.

Loop-устройство не переживает перезапуск лаборатории. Если начали заново, выполните `astra reset 13-loop-fstab`.
