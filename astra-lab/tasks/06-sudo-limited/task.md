# Ограниченный sudo для дежурного

Дежурный инженер `dezhurny` по ночам перезапускает службу планировщика `cron`, когда она зависает. Давать ему полный root нельзя.

**Нужно:**
1. `dezhurny` может выполнить `sudo systemctl restart cron` **без ввода пароля**: команду запускает скрипт мониторинга.
2. Никаких других команд через sudo ему не разрешено: ни `systemctl stop cron`, ни перезапуск других служб, ни оболочки.
3. Правило положите в отдельный файл в каталоге `/etc/sudoers.d/`. Файл `/etc/sudoers` не меняйте.
4. В группы `sudo` и `root` дежурного не добавляйте.
5. Все файлы sudoers должны проходить проверку синтаксиса.

**Подсказка:** `visudo -f /etc/sudoers.d/имя_файла`. Формат правила: `кто ALL=(root) NOPASSWD: полный_путь аргументы`. Полный путь к команде покажет `command -v systemctl`. Проверить: `sudo -l -U dezhurny` и `su - dezhurny -c 'sudo -n systemctl restart cron'`.
