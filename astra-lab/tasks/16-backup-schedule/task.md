# Расписание резервной копии и очистки

На сервере есть два готовых скрипта:
- `/usr/local/bin/backup-db.sh` — делает резервную копию в `/srv/backup`;
- `/usr/local/bin/clean-upload.sh` — удаляет из `/srv/upload` файлы старше 7 дней.

Запускать их пока никто не запускает. Настройте расписания.

**Нужно:**
1. Резервная копия: в **crontab пользователя `backup`** добавить запуск `/usr/local/bin/backup-db.sh` по будним дням (понедельник–пятница) в 02:30. Весь вывод скрипта дописывать в `/var/log/backup-db.log` (файл подготовьте так, чтобы пользователь `backup` мог в него писать).
2. Очистка: создать службу `clean-upload.service`, которая запускает `/usr/local/bin/clean-upload.sh`, и таймер `clean-upload.timer`, который запускает её каждые 15 минут.
3. Если сервер был выключен в момент запуска, пропущенный запуск таймера должен выполниться после включения.
4. Таймер должен работать сейчас и после перезагрузки.

**Подсказка:**
- `crontab -e -u backup`, формат «минута час день месяц день_недели команда», проверка `crontab -l -u backup`;
- для службы достаточно `Type=oneshot` и `ExecStart=`; в таймере — `OnCalendar=` и `Persistent=`;
- проверить выражение: `systemd-analyze calendar --iterations=3 '…'`;
- после создания файлов — `systemctl daemon-reload`, затем `systemctl enable --now clean-upload.timer`; посмотреть: `systemctl list-timers`.
