# Учебная лаборатория курса «Основы информационной безопасности»

Практические задания к урокам 02–08 курса на Stepik.

## Способ 1. В браузере, без установки (Killercoda)

Откройте ссылку на урок из курса на Stepik и зарегистрируйтесь на Killercoda (бесплатно).
Лаборатория запустится прямо в браузере. Одна сессия длится до 1 часа.

## Способ 2. На своём компьютере (Docker)

Нужен Docker Desktop (Windows, macOS) или Docker Engine (Linux).
Скачайте этот репозиторий (Code → Download ZIP), распакуйте, откройте терминал в папке `lab` и выполните:

    docker compose up -d
    docker compose exec student bash
    lab 02

Подробная инструкция — в [lab/README.md](lab/README.md).

## Лаборатория курса «Аналитик SOC первой линии»

Учебный SIEM (OpenSearch) с журналами вымышленной компании LAB и 14 заданиями — в папке `soc-lab`.
В браузере: ссылка на задание из курса на Stepik (Killercoda, сценарии `soc-task-NN`).
На своём компьютере: нужен Docker и около 4 ГБ свободной памяти; откройте терминал в папке `soc-lab` и выполните
`docker compose up -d`, подробности — в [soc-lab/README.md](soc-lab/README.md).

Всё, чему мы учимся, применяем только в своей лаборатории или там, где на это есть разрешение.
