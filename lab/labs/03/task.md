УРОК 03. DHCP и DNS: получить адрес и найти адрес
==================================================

Что вы сделаете: прочитаете, какие настройки выдал DHCP, найдёте адрес сайта
через DNS, а затем почините сломанную настройку DNS.

Часть 1. Что выдал DHCP
-----------------------
В лаборатории адреса раздаёт Docker, а не DHCP. Поэтому DHCP изучаем по журналу
настоящего обмена из учебной сети. Откройте его:
    less /opt/lab/labs/03/dhcp.log
(листать — стрелками, выйти — q)

Найдите, какой адрес получил ноутбук, какой шлюз (router) и DNS-сервер ему
выдали и на какой срок аренды (lease time).

Часть 2. Ищем адрес по имени
----------------------------
1. Посмотрите, какой DNS-сервер использует ваш компьютер:
     cat /etc/resolv.conf
2. Спросите у DNS адрес учебного портала:
     dig portal.test
   В разделе ANSWER SECTION будет строка вида:
     portal.test.   300   IN   A   192.168.10.10
   Здесь 300 — TTL в секундах, A — тип записи, последнее — адрес.
   Внизу строка SERVER показывает, какой DNS-сервер ответил.
3. Убедитесь, что сайт открывается: curl http://portal.test/

Часть 3. Поломка
----------------
1. Сломайте DNS на учебном компьютере:
     lab break dns
2. Проверьте симптомы:
     curl http://portal.test/          — по имени не открывается
     curl http://192.168.10.10/        — по адресу работает
3. Сравните два запроса:
     dig portal.test                   — через настроенный DNS
     dig @192.168.10.1 portal.test     — напрямую к DNS-серверу шлюза
   Если второй работает, а первый нет, значит, в настройке указан не тот DNS-сервер.
4. Исправьте настройку: откройте файл
     sudo nano /etc/resolv.conf
   и укажите правильный DNS-сервер — тот, что выдавал DHCP в части 1.
   (Редактируйте именно nano: команда sed -i с этим файлом в лаборатории не работает.)
5. Убедитесь, что curl http://portal.test/ снова работает.

Если совсем запутались, команда lab reset вернёт исходные настройки
(но тогда поломку придётся повторить, чтобы проверка засчиталась).

Ответы — в ~/answers/03.txt, проверка — lab check 03.
