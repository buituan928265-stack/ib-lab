# Учебная лаборатория курса ИБ

Здесь вы выполняете практические задания к видео. Лаборатория — это несколько
маленьких учебных компьютеров, которые работают на вашем компьютере в Docker:

```
  Ваша сеть 192.168.10.0/24          Соседняя сеть 192.168.11.0/24
    student 192.168.10.25  ← вы        archive.test 192.168.11.80
    portal.test 192.168.10.10
              │
           router 192.168.10.1  (шлюз, DNS, NAT)
              │
  «Интернет» 203.0.113.0/24
    delivery.test 203.0.113.80
```

Лаборатория изолирована: из неё нельзя выйти в настоящий интернет, и снаружи
к ней тоже никто не подключится. Ломать здесь можно: всё восстанавливается
одной командой.

Сейчас готовы задания к урокам 02–08 (модуль «Сети»). Для уроков 10–13 есть
необязательная Windows-часть с контроллером домена — см. [windows/README.md](windows/README.md).

## 1. Установка (один раз)

### Windows

1. Проверьте, что в компьютере включена виртуализация: откройте Диспетчер задач →
   Производительность → ЦП. Должно быть написано «Виртуализация: включено».
   Если «отключено», её включают в настройках BIOS/UEFI (пункт называется
   Intel VT-x, Intel Virtualization Technology или AMD-V/SVM).
2. Установите WSL: откройте PowerShell от имени администратора и выполните
   `wsl --install`. Перезагрузите компьютер.
3. Скачайте и установите Docker Desktop: https://www.docker.com/products/docker-desktop/
   При установке оставьте галочку «Use WSL 2».
4. Запустите Docker Desktop и дождитесь надписи «Engine running» внизу окна.

Нужно примерно 8 ГБ оперативной памяти и 3 ГБ свободного места.

### macOS и Linux

Установите Docker Desktop (macOS) или Docker Engine с плагином compose (Linux).
Лаборатория работает и на Mac с процессорами M1–M4.

### Без установки: GitHub Codespaces

Если Docker поставить не получается, откройте папку лаборатории в GitHub
Codespaces: она запустится в браузере. Нужен бесплатный аккаунт GitHub.

## 2. Запуск

Откройте терминал (на Windows — PowerShell) в папке `lab` и выполните:

```
docker compose up -d
```

Первый запуск занимает несколько минут: Docker скачивает и собирает учебные
компьютеры. Следующие запуски — секунды.

## 3. Вход в учебный компьютер

```
docker compose exec student bash
```

Вы окажетесь на компьютере ученика. Дальше всё делается командой `lab`:

| Команда | Что делает |
|---|---|
| `lab` | список заданий и что уже выполнено |
| `lab 02` | показать задание урока 02 и создать файл ответов |
| `nano ~/answers/02.txt` | вписать ответы (сохранить — Ctrl+O, Enter; выйти — Ctrl+X) |
| `lab check 02` | проверить ответы |
| `lab reset` | вернуть сеть учебного компьютера в исходное состояние |
| `exit` | выйти из лаборатории |

Проверка показывает, какие ответы верны, и даёт подсказку к неверным, не раскрывая
правильный ответ. Вопросы «своими словами» не проверяются автоматически: после
успешной проверки `lab check` покажет чек-лист для самопроверки.

## 4. Остановка, сброс и удаление

| Команда | Что делает |
|---|---|
| `docker compose stop` | остановить лабораторию; ответы сохранятся |
| `docker compose up -d` | запустить снова |
| `docker compose down` | удалить учебные компьютеры; ответы сохранятся |
| `docker compose down -v` | удалить всё, включая ответы, и начать с нуля |

## Если что-то пошло не так

- **`Pool overlaps with other one on this address space`** — у вас уже есть
  Docker-сеть с такими же адресами (часто остаётся от других проектов).
  Посмотрите список: `docker network ls`. Удалите ненужную сеть командой
  `docker network rm ИМЯ` или остановите проект, которому она принадлежит.
- **`Cannot connect to the Docker daemon` / `failed to connect to the docker API`** —
  Docker Desktop не запущен. Запустите его и дождитесь «Engine running».
- **Компьютер ученика не достаёт до соседней сети или до delivery.test** (`traceroute` показывает
  звёздочки после шлюза) на Linux с Docker 28 и новее — Docker отбрасывает такие пакеты на уровне
  хоста. Выполните на своём компьютере (не в лаборатории) `sudo sysctl -w net.bridge.bridge-nf-call-iptables=0`
  и повторите. Настройка действует до перезагрузки.
- **Сломали сеть учебного компьютера и не можете починить** — выполните `lab reset`.
- **Ответы пропали** — их удаляет только `docker compose down -v`.
