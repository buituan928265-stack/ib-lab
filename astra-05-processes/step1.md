# Astra 05: Разбор с процессами на сервере

1. Войдите в учебную машину (вы будете root):

   `lab`{{exec}}

2. Прочитайте условие:

   `astra task 05-processes`{{exec}}

3. Решите задание командами администратора.

4. Проверьте результат — проверка покажет, что верно, и подскажет, что ещё не так:

   `astra check 05-processes`{{exec}}

   Когда всё верно, проверка выдаст **код для Stepik** — введите его в курсе.

5. Нажмите **Check** внизу: Killercoda засчитает задание.

Начать заново: `astra reset 05-processes`. Список всех заданий: `astra list`.
